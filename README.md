# Bug-Fixing Commit Labelling Dataset

This repository accompanies the paper **"Labelling Bug-Fixing Commits with Open-Weight Language Models: A Reproducible Alternative to Keyword and Issue-Tracker Heuristics."** It provides the datasets, scripts, prompts, and statistical analyses required to reproduce the experiments and to build new bug-fixing commit datasets using open-weight language models.

## Datasets

### `benchmark_repo_data`

Contains the manually validated benchmark datasets used for evaluating bug-fixing commit classification.

The benchmark combines commits originating from:

- SmartSHARK
- BugsJS
- BugsInPy
- PyBugHive

Each record contains the original repository, commit hash, commit metadata, and corresponding ground-truth label, allowing every analyzed commit to be reconstructed directly from its original repository.

---

### `misc_repo_datasets`

Contains the analysis results for **33 large open-source repositories** used for large-scale evaluation.

Unlike the benchmark datasets, these repositories are not manually labelled. Instead, they contain the metadata and model predictions generated by the labelling pipeline.

Each analyzed commit stores the original repository and commit hash, enabling full reproducibility.

## Included Scripts

The repository contains the complete experimental pipeline, including:

- repository cloning
- commit extraction
- git diff generation
- prompt construction
- deterministic LLM inference through Ollama
- JSON response parsing
- keyword/stemming baseline
- dataset generation
- statistical analysis

The prompt construction logic, prompt templates, and variable substitution used during inference are included exactly as used in the experiments.

---

## Labelling Pipeline

The complete workflow is:

```
Repository
    ↓
Clone Repository
    ↓
Extract Commit History
    ↓
Extract Commit Message + Git Diff
    ↓
Apply Diff Truncation
(max. 10 files, max. 50 lines per file)
    ↓
Construct Prompt
    ↓
Run Open-Weight LLM (Ollama)
    ↓
Parse JSON Response
    ↓
Store Prediction
    ↓
Statistical Evaluation
```

All model inference was performed deterministically using:

- Temperature = 0
- Top-p = 0
- Top-k = 1

## Statistical Analysis

The repository includes the complete R scripts used to reproduce the statistical analyses reported in the paper, including:

- Accuracy
- Precision
- Recall
- F1-score
- Macro F1
- Per-dataset evaluation
- Per-repository evaluation
- Friedman test
- Nemenyi post-hoc test
- Critical Difference diagrams
